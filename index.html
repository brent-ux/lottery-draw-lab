Ticket Lab runs a fresh independent machine state for every line using the active game's mechanical profile, including the same sequential ball-by-ball loading phase used by the visualizer. Every generated line is auto-saved immediately to Saved Draw History and the latest ticket set is restored after a reload/screen change. It does not use hot/cold history or favorite numbers. White balls are displayed in ticket order (sorted); draw order and seed are retained in the metadata/export.

Model boundary: this is a deterministic, seedable 2D mechanical-process simulation, not certified lottery equipment and not a forecasting method. Every numbered ball uses the same simulated material/physics; only its number and starting state differ. Published facts, reported details and lab proxies are identified separately. Exact proprietary operating parameters that are not public remain editable rather than being presented as measured facts.
